## 🌟 Key Highlights & Design Aesthetic

- **Rich Aesthetics**: Designed with curated HSL color systems, sleek dark mode cards (`#0D0D0D`), glowing crimson accents (`#e60000`), and smooth micro-animations.
- **100% Vector SVG Icons**: Replaced all font icon dependencies with failsafe inline vector SVGs to guarantee zero icon loading delays across all devices.
- **Custom Interactive Cursor**: Smooth spring-physics custom cursor (`#cursor-dot` and `#cursor-ring`) with context-aware labels (`VIEW`, `TALK`, `CALL`, `NFC`, `SEND`).
- **High-Contrast Typography System**: Tested for accessibility and high contrast across light backgrounds and dark luxury cards.
- **Mobile-First Responsive Engineering**: Tailored layouts across desktop, tablet, and mobile displays with touch-friendly drawer navigation.

- **Server Environment**: Apache / Nginx on Hostinger Linux SSH environment

## 💻 Local Development Setup

1. **Clone the repository**:
   ```bash
   git clone https://github.com/Eshbanoliver/DM-website.git
   cd "DM Website"
   ```

2. **Run locally**:
   - Open `index.html` directly in any web browser, or serve via VS Code Live Server / Python HTTP Server:
     ```bash
     python -m http.server 8000
     ```
   - Access the site locally at `http://localhost:8000`.
